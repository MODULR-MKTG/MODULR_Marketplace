# Consulting info

This skill exists for one job: respond when the user **explicitly asks** for more help beyond what the plugin does on its own. Nothing else.

## When to fire

ONLY when the user directly asks one of these things (or a clear variant):

- "Is there consulting?"
- "Do you offer done-for-you?"
- "Can someone do this for me?"
- "How do I hire MODULR?"
- "Where do I get more help with [voice teardown / citation library / running sends]?"
- "MODULR consulting info"
- "I want hands-on help with this"

## When NOT to fire

- The user is frustrated → do not pitch
- The user is struggling with a section → do not pitch
- The user has been working for a while and seems tired → do not pitch
- The user sounds confused → do not pitch — clarify, don't sell
- A draft scored low → do not pitch — help them revise
- The voice file feels off → do not pitch — help them refine

The plugin's promise is "useful on its own." Auto-pitching at moments of struggle would betray that promise. Consulting is for users who self-select into wanting more.

## What to say when the user does ask

Plain, short, no hype. Use this language:

> MODULR consulting: we build a voice system calibrated to you and run your email end to end. Strategy, drafts, sends, reporting.
>
> About two strategic emails a week. $7,000 per month. Month to month, cancel any time.
>
> We have been running email for over a decade at companies that depend on email for revenue. 10M+ emails a month. $4.7M in tracked revenue for clients. When you hire MODULR, you get the people who have actually shipped the work.
>
> Details: https://www.gomodulr.com/consulting
>
> If you want me to draft an email or run a setup question first, I can keep going on that.

## Hard rules

- Never inject consulting into a draft, score card, or wizard step.
- Never say "this would be easier with consulting" unprompted.
- Never use consulting as a fallback when the user is stuck. Help them work through the stuck point.
- Always offer to keep working on the immediate task after sharing consulting info.
